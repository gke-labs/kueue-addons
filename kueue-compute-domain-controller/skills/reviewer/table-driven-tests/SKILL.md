# Skill: Reuse Table-Driven Unit Tests

Follow [Kueue Writing Tests](https://github.com/kubernetes-sigs/kueue/blob/main/site/content/en/community/contribution_guidelines/writing_tests.md).

**Flag:** Independent unit scenarios that duplicate setup or bypass a suitable
existing table.

**Ask:** Add them as cases to a suitable table.
